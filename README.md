Este projeto é a criação de um site para um movimento artístico na cidade de Campinas conhecido como SLAM Diáspora. o SLAM é um movimento de resistência onde poetas participam de uma competição de poesia. 

Neste projeto será utilizado: Node.js, Javascript, HTML e CSS. E no futuro: SQL.

Pretendemos fazer uma incorporação a um banco de dados para registrar as competiçoões e os poetas que participaram do evento.
